# 背景アート / 1.0.3

タイトルの世界樹と、32体それぞれの戦場を高精細なピクセルアートへ置き換えました。共通の石畳を色だけ変える方式ではなく、全32戦に異なる原画があります。ゲームボーイ風の緑系の配色に、16-bit RPGの細密な樹皮、石の彫刻、織物、氷、金属、海底遺跡の表現を合わせています。

## 世界樹と夜明け

タイトルは、古い石の門、滝、遠い城塞と世界樹が重なる景色です。左側にタイトルと操作ボタンのための暗い余白を確保し、右側に世界樹と光を配置しました。主人公と小さな光の粒は背景より手前に描画します。

同じ原画を、タイトルでは緑系の色変換を通し、エンディングでは本来の色で表示します。32体を倒すと、同じ景色に葉の緑、夜明けの金色、遠景の青紫が戻ります。

## 制作と組み込み

組み込みの `image_gen` で1背景ずつ制作した、計33枚のオリジナルPNGです。既存ゲームからの画像抽出や、手作業でのピクセル打ちとしての表示はしていません。原画は変更せず [`app/src/main/assets/backgrounds`](../app/src/main/assets/backgrounds/) に同梱しました。[全生成プロンプト・元ファイル名・SHA-256](background-prompts.json)を保存しています。ピクセルアートと配色の指定は制作上の方向性であり、厳密な4色への減色を意味しません。

1.0.4では、タイトル・戦場の背景の原画全体を表示枠へ広げ、横長画面の左右まで描画します。背景の縦横倍率は表示枠に合わせ、キャラクター・文字・戦闘判定には一定の縦横倍率を使います。ボス紹介の背景のみ、縦横比を保って枠へ合わせ、外周を中央基準で切り抜きます。平滑化を無効にして描画し、長辺2048px以下へサンプリングして読み込みます。背景キャッシュの上限は16 MiB。全33枚を同時に展開せず、戦闘中は同じ画像を再利用します。実行時の通信は不要です。

戦場の装飾は主に上端と左右へ配置し、中央の床は低いコントラストにしました。背景の輝度を描画時に緑系の一定範囲へ収め、雪・雷・太陽の絵も淡い予兆より明るくならないようにします。番号付きの位置目印、予兆、安全地帯、足元の当たり判定マーカーは背景より手前に描きます。装飾の根・壁・網は背景であり、追加の障害物や攻撃判定を持ちません。

ボス紹介にも同じ専用背景を使用します。戦闘ルール、移動範囲、当たり判定、楽曲、SEは従来の処理を使います。
