# 召喚士の調整（1.0.16 / code 17）

2026-09-10に実装・検証し、Pixel 10aへ更新しました。

## はにわ

召喚士が受けるダメージ1回分を、はにわがすべて肩代わりして消滅します。正面からの攻撃だけを75%軽減する旧仕様を置き換えました。

- 出現時間は**全レベルで最長5秒**。被弾しなくても時間切れで消滅します。
- 正面・背後・床の範囲攻撃・突進・必殺技など、攻撃の方向や形状を問わず肩代わりします。吹き飛ばしによる壁衝突ダメージも対象で、吹き飛ばし自体は継続します。
- 肩代わりした分はHPにも被ダメージスコアにも加算しません。破片の演出・陶器のSE・「はにわが身代わりになった！」の表示を出します。
- 1回を肩代わりした時点で召喚枠を解放します。同時に別の攻撃が重なっている場合、次の攻撃は通常どおり判定し、身代わりによる追加の無敵時間はありません。
- 回避した攻撃や、すでに無敵時間・透明化で防いだ攻撃では消費しません。
- 出現中の再タップによる近接攻撃は継続できます。近接攻撃で寿命は延長されません。近接攻撃の威力・範囲・待機時間・演出は従来どおり成長します。
- 一時停止・カットイン中は、従来の召喚と同じく寿命の時計も止まります。残り時間バーも5秒を上限として表示します。

## 白ウサギ

**全レベルで、1回の回復量を従来の半分**にしました。

| 技レベル | 以前 | 1.0.16 |
| --- | ---: | ---: |
| Lv.1 | 16 | 8 |
| Lv.8 | 38.4 | 19.2 |
| Lv.16 | 64 | 32 |

Lv.1が最大値の25%となる直線成長、回復間隔2秒、初回の回復タイミング、成長する回復範囲、出現時間12〜20秒は維持しています。技の詳細表示は「威力」から「回復」へ変更しました。

通常召喚の上限2体、巨人の性能、必殺技の巨人5体、召喚ゲージ回復速度・消費・待機時間は変更していません。保存形式もversion 2のままです。
