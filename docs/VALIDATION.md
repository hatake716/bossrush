# BOSSRUSH 1.0.6 検証記録

検証日：2026-09-09。Android 8.0以上、applicationId `io.github.hatake716.bossrush`、versionName `1.0.6`、versionCode `7`。

## 今回の変更

カットインを各戦闘の初回だけにしました。HP1/3の初回は3秒のカットインを表示します。覚醒後は通常技と必殺技をランダムに使い、必殺技の再使用では画面を切り替えず、移動・戦闘時計・技の長押しを継続します。次のボス戦では初回表示が復活します。

カットイン背景は同じボスの攻撃エフェクトの主色と連動します。広い背景面を主色のグラデーションにし、副色は放射線・光粒に使います。32体すべてで背景に主色が現れることを画素検査しました。[戦闘と配色](COMBAT.md)を参照してください。

外部コントローラーに対応しました。左スティック／十字キー、A・B・X・Y、L1／R1、L2、STARTで移動・技・アイテム・一時停止を操作できます。メニューの選択枠、確認ダイアログのA／B、切断時の一時停止、ゲーム内の操作説明も追加しました。[操作一覧](CONTROLS.md)を参照してください。

フォーカス取得時にAndroid標準の選択表示が画面全体を白くする問題も修正しました。Canvas内の選択枠だけを描き、足元と背景・エフェクトの元の色を維持します。全16パターンの足元の画素検査を含め、修正版で下記の全テストを再実行しています。
