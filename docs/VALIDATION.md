## 単体テストが確認する内容

- 4職業の全技について、初期25%・最大Lv.16・直線の威力/範囲/待機曲線。
- 召喚ゲージの回復速度が厳密に半分であること、2体制限、時間切れ、巨人の攻撃、ウサギの回復、はにわの正面防御と再使用。
- 近接射程、矢と炎の飛翔、氷の時間差、休む際の移動不能と終了時回復。
- HP1/3のカットインが大ダメージでも省略されず、1回だけ発動すること。
- 一時停止、通常/特殊共通の5個制限、盗むの各ボス1回制限、無敵・分身・砂時計・黄金の印、戦利品交換。
- スコアが時間と被ダメージに応じて変化すること。
- 全16種類の予兆に安全地帯があり、四隅から通常の移動速度で届く猶予があること。後続の必殺技が前の予兆と不当に重ならないこと。
- **4職業×32ステージ**について、育成した構成の30秒ダメージ試算とボスHPの単調増加。
- **4職業×32戦の進行**について、撃破→1つ強化→盗賊の戦利品→ショップ→次戦→エンディングの状態遷移。このテストでは撃破状態を直接作り、実際の回避操作は行いません。
- 全32曲が無音でなく、波形が互いに異なり、合成値が範囲内であること。4曲の12秒WAV試聴ファイルも生成。

## エミュレーターの操作検証

API 35 / x86_64 / 2400×1080の横画面。対象は明示的に `emulator-5554` を選択。`GameplayTest` は物理端末での実行を拒否します。

最終APKで **4件成功、失敗0件（85.8秒）**。配布用APKとエミュレーターへのインストール対象は同じファイルです。

1. **通常のタッチ入力で戦士が最初のボスを撃破**。テストは画面上の予兆の状態を読み、主人公の位置を判断してAndroidへ2本指のタッチ入力を送ります。HPやダメージ値を変更せずに攻撃・回避し、カットイン・勝利を確認。その後に技を1つ強化し、ショップで購入し、Activity終了後に保存した職業/技レベル/お金/次のボスを復元します。
2. **4職業のボタンと同時入力**。左側の移動と右側の技が同時に働くこと、召喚が出現すること、Homeへ移ると時間が止まり、アプリへ戻ると再開できることを確認します。満タン時の薬草の不消費と、アイテム画面から通常の一時停止への復帰も確認します。
3. **図鑑**。4ページを進み、32体目のオーディンを選択できることを確認します。
4. **終盤のテスト用状態**。盗賊の所持品5個からの特殊品交換と、32体目撃破後の成長選択、カラーのエンディング、最高スコア保存を確認します。ここでは長い冒険を省略するため、テストコードが終盤状態を準備します。実操作による32連戦クリアの証明ではありません。

再現コマンド：

```sh
tools/test-emulator.sh emulator-5554
```

この操作テストはエミュレーター内の本アプリの保存データを初期化します。結果ログは `artifacts/instrumentation.txt`、画面画像は `artifacts/screenshots/` に保存します。
