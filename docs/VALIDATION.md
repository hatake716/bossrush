# BOSSRUSH 1.0.5 検証記録

検証日：2026-09-09。Android 8.0以上、applicationId `io.github.hatake716.bossrush`、versionName `1.0.5`、versionCode `6`。

## 今回の変更

全32体に合計66種類の専用通常攻撃を用意しました。攻撃の形、現在・過去の位置への照準、方向の切り返し、段数をボスごとに定義しています。後半ほど基礎攻撃力を上げ、基準予兆と攻撃後の間隔を短縮し、三〜四段の連撃を増やしました。通常速度で到達できる安全地点を調べて予兆の猶予を確保し、各段の判定を終えてから次の予兆を出します。

HP1/3での初回カットイン後は通常攻撃と必殺技をランダムに使います。通常技1〜3回の間に必殺技を再使用し、2回目以降も1.6秒のカットインを挟みます。必殺技には全32体固有の配色を使い、鮮やかな光柱・光線・輪・属性の破片を追加しました。安全な中心と主人公の足元は手前に保ちます。[攻撃一覧と難易度・配色](COMBAT.md)を参照してください。

キャラクター39枚・背景33枚、BGM・SE、画面幅への対応、主人公の技と30秒基準のボスHP計算は維持しています。
