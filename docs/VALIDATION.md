# BOSSRUSH 1.0.2 検証記録

検証日：2026-09-09。Android 8.0以上、applicationId `io.github.hatake716.bossrush`、versionName `1.0.2`、versionCode `3`。

## 今回の変更

4職業・32ボス・3召喚獣の全39体を専用の透過PNGへ置き換えました。職業の装備、動物の毛並み・羽根・鱗、神々の衣装と神話上の持ち物を描き分けています。タイトル、職業選択、戦闘、HUD、召喚、ボス紹介、必殺技カットイン、図鑑、エンディングへ組み込みました。[制作方針・画像一覧・生成プロンプト](ART.md)を参照してください。

神話図鑑の画像をタップすると拡大表示でき、前後のボスへ移動できます。Androidの戻る操作で選択中の図鑑ページへ戻ります。拡大中の仮想アクセシビリティボタンは拡大画面のものだけになり、ボス名と説明も読み上げ用の情報へ反映します。日本語の折り返しでは、句点・閉じ括弧を次の行の先頭へ残さないようにしました。

戦闘の射程、当たり判定、ダメージ、成長、楽曲・SEの処理は変更していません。画像は長辺512px以下へサンプリングして読み込み、縦横比を維持して表示枠に収めます。キャッシュ上限は6 MiBです。

## エミュレーター

API 35 / x86_64 / 2400×1080横画面、対象 `emulator-5554`。**最終APKで7件成功、失敗0件、121.880秒**。

```sh
tools/test-emulator.sh emulator-5554
```

1. **39体の描画検査**：全画像をAndroidで読み込み、不透明な本体と透明な外周があること、指定した描画枠の外へはみ出さないことを確認。Android Canvasによるボス8体ずつの一覧4枚と、4職業・3召喚獣の一覧1枚を生成し、全画像を目視確認しました。
2. **拡大図鑑の実操作**：画像をタップして拡大し、32体を順に閲覧。最初・最後の移動制限、前の神へ戻る操作、選択ページへの復帰、Androidの戻る操作を確認。代表6体の実画面を取得しました。
3. **予兆と攻撃演出**：全16パターンと代表9体の属性演出を描画用の状態で確認。主人公の足元が手前に残り、安全円が発動演出で塗りつぶされず、描画自体が追加ダメージを発生させないことを検査しました。
4. **戦士の戦闘**：二本指のタッチ入力で最初のボスを回避・攻撃して撃破。HPや攻撃量を直接変更せず、カットイン、成長、ショップ購入、Activity終了後の保存再開まで確認しました。
5. **4職業の操作**：技ボタン、移動と技の同時入力、巨人の召喚、バックグラウンドでの時間停止と復帰、満タン時の薬草の不消費、アイテム画面からの一時停止を確認しました。
6. **通常の図鑑**：全4ページを巡り、オーディンの情報と楽曲説明を確認しました。
7. **盗賊とエンディング**：満杯の所持品から特殊品を交換し、32体目の撃破後の成長、カラーエンディング、最高スコアの保存を確認しました。終盤状態はテストコードで準備しています。

通常の操作テストと、描画用・終盤用の状態を区別しています。人による実操作の32連戦クリアではありません。テストはエミュレーター内の本アプリの保存データを初期化し、物理端末での自動操作を拒否します。

ログは `artifacts/instrumentation.txt`、画像は `artifacts/screenshots/`。公開用の画像は `docs/screenshots/` に保存しています。`art-bestiary-*.png` と `art-party.png` は描画確認用の一覧です。`portrait-*.png`、職業選択、戦闘、カットインはアプリの実画面から取得しています。
