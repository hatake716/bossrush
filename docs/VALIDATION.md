# BOSSRUSH 1.0.3 検証記録

検証日：2026-09-09。Android 8.0以上、applicationId `io.github.hatake716.bossrush`、versionName `1.0.3`、versionCode `4`。

## 今回の変更

タイトルの世界樹と全32戦の背景を、1672×941pxの専用ピクセルアートへ置き換えました。原画は計33枚。森、雪山、海底宮殿、沈船、冥界、火山、神々の砦を、各ボスのモチーフに合わせて描き分けています。ボス紹介にも同じ背景を使用します。[32戦の意匠・制作方法・生成プロンプト](BACKGROUNDS.md)を参照してください。

タイトルでは緑系に変換した世界樹の景色を表示し、クリア後は同じ原画の色を戻します。主人公を石畳の上へ配置し、下部の文字には暗い背面を付けています。

背景は長辺2048px以下へサンプリングして読み込み、平滑化せず、縦横比を保って表示枠へ収めます。背景キャッシュの上限は16 MiBです。戦闘の床は低いコントラストにし、描画時の輝度調整で予兆より明るくならないようにします。

既存の4職業・32ボス・3召喚獣の39枚の画像、キャラクター用6 MiBキャッシュ、当たり判定、ダメージ、成長、BGM・SEは従来の処理を維持します。

3. **39体の描画**：各キャラクターの不透明な本体、透明な外周、描画枠への収まりを確認しました。
4. **拡大図鑑の実操作**：32体を順に閲覧し、最初・最後の移動制限、前の神へ戻る操作、図鑑ページへの復帰、Androidの戻る操作を確認しました。
5. **予兆と攻撃演出**：全16パターンと代表9体の属性演出を確認。足元が手前に残り、安全円を維持し、描画自体が追加ダメージを発生させないことを検査しました。
6. **戦士の戦闘**：二本指のタッチ入力で最初のボスを回避・攻撃して撃破。HPや攻撃量を直接変更せず、カットイン、成長、ショップ購入、Activity終了後の保存再開まで確認しました。
7. **4職業の操作**：技ボタン、移動と技の同時入力、巨人の召喚、バックグラウンドでの時間停止と復帰、満タン時の薬草の不消費、アイテム画面からの一時停止を確認しました。
8. **通常の図鑑**：全4ページを巡り、オーディンの情報と楽曲説明を確認しました。
9. **盗賊とエンディング**：満杯の所持品から特殊品を交換し、32体目の撃破後の成長、カラーエンディング、最高スコアの保存を確認しました。終盤状態はテストコードで準備しています。

原画の初回読み込みを含むボス紹介の撮影では、「戦闘開始」ボタンの表示を待ってから取得するようにしています。最終版のタイトル、ボス紹介、攻撃発動、安全地帯、カラーエンディングの実画面も目視確認しました。

通常の操作テストと、描画用・終盤用の状態を区別しています。人による実操作の32連戦クリアではありません。テストはエミュレーター内の本アプリの保存データを初期化し、物理端末での自動操作を拒否します。

ログは `artifacts/instrumentation.txt`、画像は `artifacts/screenshots/`。公開用画像は `docs/screenshots/` に保存しています。`backgrounds-*.png` はゲームの描画処理で戦場を並べた検証用一覧です。`art-bestiary-*.png` と `art-party.png` はキャラクターの描画確認用一覧です。エンディングとVFXの実画面は、明示したテスト用状態から取得しています。
