# キャラクターアート / 1.0.2

ゲームボーイ風の緑系の世界に、16-bit RPGのボスのような細密な陰影と装飾を合わせました。4職業、32ボス、3召喚獣の全39体を別々に制作し、共通の獣・神の絵に装飾だけを加える方式から置き換えています。

## 制作方法

組み込みの `image_gen` で、各キャラクターにつき1回ずつ生成した透過PNGを使用しています。ロマンシング サガ時代の細密なピクセルアート表現を方向性とし、神話上の持ち物と本作の緑色の配色を指定しました。既存ゲームから画像を抽出したものではありません。人が1ピクセルずつ打った作品としての表示はしていません。

画像本体は [`app/src/main/assets/sprites`](../app/src/main/assets/sprites/)。共通の画風指定、各体のプロンプト、生成ファイル名、SHA-256は [`art-prompts.json`](art-prompts.json) に記録しています。生成されたPNGを変更せずコピーし、元のアルファを保持しています。画像内の階調数や論理ピクセル数は生成時の意図であり、厳密に8色・160pxへ減色した画像という意味ではありません。

## ゲームへの組み込み

`CharacterAtlas` は原画を長辺512px以下へサンプリングして読み込み、ほぼ透明な外周を除いた範囲で縦横比を合わせます。平滑化を使わずに描画し、キャッシュは6 MiBまで。全39枚の原寸画像を同時に展開しません。

タイトル、職業選択、戦闘、召喚、HUD、ボス紹介、必殺技カットイン、図鑑、エンディングに同じ専用画像を使用します。クリア後の主人公は描画時の色変換で暖色に戻します。1.0.3で世界樹と戦場も[専用の背景画像](BACKGROUNDS.md)へ置き換えました。アイコンはCanvas描画を保っています。

図鑑の画像をタップすると拡大表示になり、「前の神」「次の神」で順に見られます。「図鑑へ戻る」またはAndroidの戻る操作で選択中のボスのページへ戻ります。拡大中のアクセシビリティ操作対象は、拡大画面のボタンだけです。

ボスの画像の大きさを当たり判定に流用せず、移動・射程・予兆・ダメージは既存の戦闘処理を使用します。主人公の足元の小円は画像と攻撃演出より手前に描画します。
