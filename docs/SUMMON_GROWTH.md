# 召喚の成長（1.0.17 / code 18）

はにわの耐久と持続時間が技レベルで成長し、白ウサギはLv.1の回復量8を維持して最大16へ成長するよう調整しました。以前の固定耐久・時間の記録は [1.0.16の調整](SUMMON_BALANCE.md) にあります。

## 成長値

| 技レベル | はにわの耐久 | はにわの持続時間 | 白ウサギの1回の回復量 |
| --- | ---: | ---: | ---: |
| 1 | 1回 | 5秒 | 8 |
| 2 | 1回 | 6秒 | 約8.53 |
| 5 | 1回 | 9秒 | 約10.13 |
| 6 | 2回 | 10秒 | 約10.67 |
| 8 | 2回 | 12秒 | 約11.73 |
| 10 | 2回 | 14秒 | 12.8 |
| 11 | 3回 | 15秒 | 約13.33 |
| 15 | 3回 | 19秒 | 約15.47 |
| 16 | 4回 | 20秒 | 16 |

```text
L = 技レベルを1〜16へ制限した値
はにわの耐久 = 1 + floor((L - 1) / 5)
はにわの持続時間 = L + 4 秒
白ウサギの回復量 = 8 + 8 × (L - 1) / 15
```

耐久は攻撃の整数回数なので、Lv.6・11・16で1回ずつ増えます。持続時間は毎レベル1秒、回復量は毎レベル約0.533ずつ増えます。白ウサギの回復量は小数のままHPへ反映し、強化画面では小数第1位まで表示します。Lv.1の8は最大16の50%に当たり、ほかの攻撃技の25%開始とは別の曲線です。

## 戦闘中の挙動と表示

- はにわは1発分のダメージを完全に肩代わりするたびに耐久を1消費します。残り耐久が0になるか、持続時間が終わると消滅し、召喚枠を空けます。
- 方向・範囲・突進・通常技・必殺技を問わず肩代わりします。重なった攻撃も1発ずつ消費し、Lv.16なら最初の4発を防いで5発目を受けます。追加の無敵時間はありません。
- 回避・既存の無敵時間・透明化で防いだ攻撃では耐久を消費しません。肩代わりしたダメージはスコアの被ダメージ減点に加算しません。吹き飛ばし自体は従来どおりで、壁衝突時のダメージが身代わりの対象です。
- 出現中の再タップによる近接攻撃は維持します。攻撃や肩代わりで耐久・寿命は回復しません。消滅後に新しく召喚すれば、その技レベルの最大耐久・時間で出現します。
- 一時停止・カットイン中は、従来どおり持続時間の進行も止まります。
- 右側のステータス欄に「はにわ 耐久3/4回・残り18秒」のように表示します。戦場の人物や攻撃演出に隠れず読める位置です。召喚獣の寿命バーも、内側の残量が描画できる高さへ調整しました。
- 強化画面では、はにわの耐久・持続時間と白ウサギの回復量を、選択中の次レベルの値で確認できます。選択を取消すと現在の値へ戻り、確定するまでレベルは保存されません。

白ウサギの回復間隔2秒・初回回復のタイミング・回復範囲・召喚時間12〜20秒、通常召喚の上限2体、召喚ゲージ、近接攻撃、巨人、必殺技の巨人5体は維持しています。保存形式はversion 2のままで、以前の技レベルを引き継ぎます。
