# 神話と制作上のアレンジ

参照した一次資料：

- [散文エッダ、R. B. Anderson英訳（1901年版）](https://www.gutenberg.org/files/18947/18947-h/18947-h.htm)。Gylfaginning（The Fooling of Gylfe）には世界樹、神々、狼、ロキの子供たち、ラグナロクなどの記述があります。Skaldskaparmal（Brage's Talk / The Poetical Diction）にはスィアチ、イズン、ニョルズとスカジ、フルングニル、鍛冶の宝物などの記述があります。
- [古エッダ、H. A. Bellows英訳（1923年）](https://www.gutenberg.org/files/73533/73533-h/73533-h.htm)。Völuspá（Voluspo）の終末と再生、Grímnismál（Grimnismol）の世界と眷属、Þrymskviða（Thrymskvitha）の盗まれた鎚などを参照しています。

神話には異伝があり、英訳の解釈や名前の表記も異なります。図鑑は短い導入であり、原典全文の代わりではありません。ボス順、危険地帯の形、必殺技の名前、世界から色が消えた筋書きは本作独自の設定です。

## 戦場への翻案

- リス・鹿・猪：枝の間を走る動きを直線予兆に、角や牙を扇形に翻案。
- 鴉：思考を交差線と格子に、記憶を足跡に残る円の予兆に翻案。
- 日月を追う狼：日蝕・月蝕を、月印だけが安全な暗い戦場に翻案。
- 鷲の巨人：風は吹き飛ばし、羽は直線と着弾範囲、奪われた林檎は受け止める円の試練。
- スカジ・ウル：狩猟と弓を矢列・狙撃・交差する射線で表現。
- 海の存在：波は横帯、網は格子、渦潮・世界蛇は内側が安全な輪。
- ヘル：半身の対比を左右の安全・危険で表現。フェンリルの鎖は十字、解放は吹き飛ばし。
- 石と炎の巨人：砥石の破砕を着弾円、炎剣を半面の薙ぎ払いに翻案。
- イズンの林檎やテュールの誓い：円に入って受け止める試練。入らない場合にダメージを受ける、1人用の塔ギミック。
- ヘイムダルの角笛：波の予兆。トール：雷の十字と吹き飛ばし。オーディン：槍の射線、鴉の交差、知恵を試すルーン。

全体は16種類の予兆形状を組み合わせ、32体それぞれの順番と場面をデータで定義しています。1/3のHPしきい値を大ダメージで飛ばすことはできず、カットインは各戦闘1回発生します。予兆確定時に判定し、その後の残光へ入っても追加ダメージは発生しません。連続攻撃は前の予兆の猶予が延びた場合に後続も遅延させます。

## オリジナル楽曲の構成

32曲は `Content.kt` の各ボスに、曲名、BPM、基準音、8音の専用モチーフ、和声のモードを保持します。`ScoreSynth` はそれぞれを4フレーズに展開し、高いオクターブの反復、アルペジオ、ベース、パルス波のデューティ比、ノイズのリズムで合成します。

- ラタトスクは跳躍の多い上行モチーフ。鹿や黄金の猪は角笛や明るい長調を意識。
- 鴉は疑問と記憶を表す折り返す旋律。狼は速いテンポと短調。
- 山・弓の神々は高い音域。海は低い基準音と波のような分散和音。
- 冥界と竜は半音を含む暗い動き。石の巨人は三角形を意識した3音の反復。
- 黄金の庭は明るい上行と抒情的な反復。ロキは半音と不安定な跳躍。
- トールは200 BPMの反復低音。オーディンは既出の上行・下降をまとめる広い音域。
- エンディングは独立した32音の長調の旋律、78 BPM、柔らかい音量の変化で夜明けを表現。

神話の音楽を復元したものでも、既存ゲームの曲のアレンジでもありません。音源は22,050 Hz・16 bit・モノラル。BGMと効果音はゲーム内で生成され、音声ファイルは配布APKに同梱しません。単体テストは試聴用の12秒WAVを `artifacts/music/` に出力します。

## 描画

画像は自作のピクセル形状です。人物、獣、鳥、竜などは共通の骨格と個別の装飾・持ち物を組み合わせます。32体すべてが別々の外部画像ファイルになっている構成ではありません。画面は960×540の論理座標を縦横比を保って拡大します。48×48のスプライトは補間せず拡大し、日本語だけは読みやすさのためAndroidのフォントを使用します。
