# 1.0.14 戦闘曲の個別作曲・検証記録

2026-09-10。versionName `1.0.14` / versionCode `15`。

## 変更した内容

32体すべての戦闘曲に、4小節の主題Aと応答Bを個別に記譜。音程だけでなく、音価、休符、付点・三連符、音域、発音の長さを指定した。ギターとベースにもそれぞれの譜面を用意し、キック・スネア、伴奏を薄くする位置、主題の再現位置を曲ごとに設定した。

旧版の共通した四分音符の主旋律＋裏拍の装飾という戦闘曲生成を廃止。強拍の旋律を自動的に近い和音構成音へ丸める処理も使用しない。ピアノ左手はZUN進行の長三和音・短三和音を鳴らし、主旋律は記譜どおりに演奏する。

- 全32曲で♭VI → ♭VII → i → i、ピアノ＋エレキギター・ベース・ドラムを維持。
- 192〜232 BPM、28.235〜32.308秒の完全な小節でループ。拍子と既存の曲の長さは維持。
- タイトル・各メニューは引き続きBGMなし。
- ショップ・エンディングのOggとMIDIは1.0.13時点のファイルとバイト単位で一致。
- 戦闘・必殺技・SE・セーブ形式の変更なし。神話図鑑の曲の説明を新しい編曲に同期。

## 作曲・音声の検査

`python3 tools/check-music.py` および NumPy入りPythonによる `tools/check-music.py --audio` が成功。

- 全32曲の発音位置が異なる。主題Aの音数は4小節あたり7〜31音。
- 移調を除いた主題Aの音程差列も32種類。最も近い組のSequenceMatcher一致度は0.6939で、同一輪郭や長い輪郭の再利用を検出する上限0.8を下回った。
- 記譜・編曲から計算した**全楽器のノートが納品MIDIと一致**。音声とMIDIのハッシュだけによる曲の違いの判定ではない。
- 音声34曲のOgg粒度・PCM長・44.1 kHz・左右チャンネル・音量・ピーク・端点を確認。
- 戦闘曲の実測は−15.25〜−14.99 LUFS、最大の真のピークは−1.88 dBTP。10ms単位の予期しない無音区間なし。約1.45msのランタイム接続補正後、末尾と先頭のサンプルが一致。

譜面の数値比較は共通の生成パターンへ戻る不具合の防止に使う。曲の良さや実機での聴感を数値だけで保証するものではない。新旧比較と主旋律の独奏を用意し、ユーザーが聴き比べられるようにした。
