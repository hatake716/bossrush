# コンテンツレーティング（IARC）とデータセーフティの回答

BOSSRUSH v1.0.20。Play Console のフォームに入力する際の回答案と、その根拠です。

**根拠の中心**: `app/src/main/AndroidManifest.xml` に `<uses-permission>` が **1件も存在しません**。
INTERNET 権限がないため、このアプリはネットワーク通信が技術的に不可能です。
`app/build.gradle.kts` の依存も `androidx.core:core-ktx` / `androidx.activity:activity-ktx` と
テスト用ライブラリのみで、広告・解析・課金・クラッシュレポートの SDK を一切含みません。

---

## 1. コンテンツレーティング（IARC 質問票）

| 質問項目 | 回答 | 根拠 |
|---|---|---|
| 暴力表現（全般） | **あり（軽度・非写実的）** | 剣・弓・魔法で神話上の獣や神と戦う。撃破時はドット絵が破片になって砕ける演出（`BossDefeatEffects.kt`、`docs/BATTLE_PRESENTATION.md`） |
| 写実的な暴力 / 流血表現 | **なし** | 血液の描写・スプラッタ表現なし。緑単色のピクセルアートで、撃破は光と破片の抽象的な演出のみ |
| 人間キャラクターへの暴力 | **なし〜軽微** | 対戦相手は神話上の獣・巨人・神。人型のボス絵もあるが、描写は非写実的なドット絵で負傷表現なし |
| 性的表現・ヌード | **なし** | 全39体のキャラクターは装束・鎧を着用（`docs/ART.md`）。性的な描写・示唆・恋愛描写なし |
| 言語（不適切な言葉） | **なし** | 全173ページの台本が `docs/STORY_SCRIPT.md` に全文あり。冒涜語・罵倒語・卑俗語なし |
| 恐怖・ホラー表現 | **軽微** | 冥界・死者の国・竜など神話由来のモチーフはあるが、驚かせる演出やホラー的描写はなし |
| 規制対象物（アルコール・タバコ・薬物） | **なし** | 「薬草のしずく」「力の霊薬」等は明確なファンタジー回復アイテム（`Content.kt` の `Item`）。実在の薬物・酒類・タバコの描写や使用促進はなし。「宴」はエーギルの神話モチーフとしての曲名・背景のみで、飲酒行為の描写なし |
| ギャンブル | **なし** | 賭博要素・ガチャ・ルートボックス・仮想通貨の賭けなし。盗賊の戦利品は4択からプレイヤーが選ぶ確定入手 |
| ユーザー間の交流（チャット・SNS等） | **なし** | INTERNET 権限なし。オンライン機能・チャット・掲示板・UGC なし |
| ユーザー生成コンテンツの共有 | **なし** | 共有機能なし |
| 位置情報の共有 | **なし** | 位置情報の取得も共有もなし。位置情報権限なし |
| 個人情報の収集・共有 | **なし** | 個人情報を一切収集しない。保存は SharedPreferences（`bossrush`）のみで端末外へ出ない |
| アプリ内購入 | **なし** | 課金モジュール未実装。Billing ライブラリ依存なし |
| デジタル購入（有料アプリ本体） | 該当（アプリ本体が有料） | ストアでの単価販売。アプリ内での追加購入はなし |

**想定レーティング**: IARC 汎用 7歳以上前後 / ESRB E10+ / PEGI 7 相当。
ファンタジー暴力の軽度描写のみを根拠とする想定です。最終判定は IARC の回答結果に従います。

## 2. データセーフティ（Data safety）

### 2-1. 全体

| 設問 | 回答 | 根拠 |
|---|---|---|
| このアプリはユーザーデータを収集または共有しますか | **いいえ** | INTERNET 権限がなく、データが端末外へ出る経路が存在しない |
| データはサードパーティと共有されますか | **いいえ** | ネットワークライブラリ・SDK・アナリティクス・広告 SDK のいずれも未使用 |

### 2-2. データ種別ごとの申告

| データ種別 | 収集 | 共有 | 備考 |
|---|:--:|:--:|---|
| 位置情報 | なし | なし | 位置情報 API 未使用、権限なし |
| 個人情報（氏名・メール・ユーザーID・住所・電話番号等） | なし | なし | アカウント機能なし |
| 財務情報 | なし | なし | アプリ内課金なし |
| 健康・フィットネス | なし | なし | — |
| メッセージ | なし | なし | 通信機能なし |
| 写真・動画・音声 | なし | なし | カメラ・マイク権限なし |
| ファイルとドキュメント | なし | なし | ストレージ権限なし |
| カレンダー・連絡先 | なし | なし | — |
| アプリのアクティビティ | なし | なし | 端末内保存のみで送信しない |
| ウェブ閲覧履歴 | なし | なし | WebView 未使用 |
| アプリの情報とパフォーマンス（クラッシュログ・診断） | なし | なし | Crashlytics 等の自動レポート SDK 未導入。Play Console が自動収集する分は Google 側の扱い |
| デバイスID・その他ID | なし | なし | 広告IDやデバイスID未取得 |

### 2-3. セキュリティ関連

| 設問 | 回答 | 備考 |
|---|---|---|
| データは転送時に暗号化されますか | **該当なし** | 収集「いいえ」を選ぶとこの設問は表示されません |
| ユーザーはデータの削除をリクエストできますか | **該当なし** | 端末内のセーブデータは Android の「設定 → アプリ → BOSSRUSH → ストレージ → データを削除」でユーザー自身がいつでも消去できます |
| ファミリーポリシー対象ですか | 対象年齢を全年齢に設定する場合のみ該当 | 対象年齢を13歳以上に限定すれば適用外にできます |
| プライバシーポリシーURL | **必須（要準備）** | 下記参照 |

**補足**: `android:allowBackup="false"` を設定しているため（`AndroidManifest.xml`）、
セーブデータの Google ドライブ自動バックアップも行われません。「端末内のみ」という説明と
実装が完全に一致しています。

`play/listing/privacy-policy.md` に本文を用意しました。GitHub Pages 等に公開し、
